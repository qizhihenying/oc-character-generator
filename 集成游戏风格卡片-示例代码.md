```typescript
// 在 App.tsx 顶部的 state 声明中添加
```

```typescript
// 在 MJDrawButton 的回调中
<MJDrawButton
  prompt={currentPrompt.prompt}
  onConfigClick={() => setShowMJConfig(true)}
  onImageGenerated={(imageUrl) => {
    setMjGeneratedImage(imageUrl); // 保存生成的图片
  }}

```

```typescript
<GameStyleCard

/>
```

## 💡 提示

### 只在有 IP 设定时显示
当前代码只在 `currentPrompt.characterIP` 存在时才显示游戏风格卡片。

如果想总是显示，改为：
```typescript
{currentPrompt && (
  <GameStyleCard
    prompt={currentPrompt}
    characterImage={mjGeneratedImage}
  />
)}
```

### 调整显示位置
你可以把游戏风格卡片放在任何位置：
- 放在最前面：最先看到
- 放在中间：在文字卡片和 IP 卡片之间
- 放在最后：作为总结展示

### 隐藏原有卡片
如果只想显示游戏风格卡片，可以注释掉原有的 `CharacterCard`：

```typescript
{/* 
<CharacterCard
  prompt={currentPrompt}
  onCopy={handleCopy}
  isCopied={copiedId === currentPrompt.id}
/>
*/}
```

复制这段代码，直接替换 App.tsx 中的相应部分：

```typescript
// 1. 在顶部添加导入
import GameStyleCard from './components/GameStyleCard';

// 2. 在 currentPrompt 显示区域（约第 303 行）
{currentPrompt && (
  <>
    <MJDrawButton
      prompt={currentPrompt.prompt}
      onConfigClick={() => setShowMJConfig(true)}
    />

    <ImagePreview 
      prompt={currentPrompt.prompt}
      seed={currentPrompt.seed}
    />
    
    <CharacterCard
      prompt={currentPrompt}
      onCopy={handleCopy}
      isCopied={copiedId === currentPrompt.id}
    />
    
    {/* 游戏风格卡片 */}
    {currentPrompt.characterIP && (
      <div className="mt-8">
        <div className="text-center mb-6">
          <h2 className="text-3xl font-bold gradient-text inline-block">
            🎮 游戏风格角色卡
          </h2>
          <p className="text-gray-500 dark:text-gray-400 mt-2">
            点击下方按钮下载精美卡片
          </p>
        </div>
        <GameStyleCard
          prompt={currentPrompt}
          characterImage={undefined}
        />
      </div>
    )}

      <CharacterIPCard
        characterIP={currentPrompt.characterIP}
        onCopy={handleCopy}

            ...currentPrompt,
            characterIP: enhancedIP

            h.id === currentPrompt.id ? updatedPrompt : h
          ));
          setMultiDrawResults(multiDrawResults.map(m =>

        }}
```
