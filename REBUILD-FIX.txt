========================================
  BUILD ERROR FIX
========================================

ERROR:
------
remove chrome_100_percent.pak: Access is denied.

CAUSE:
------
The dist-electron folder is locked because:
1. The app is still running
2. Files are being used by another process
3. Windows file lock issue

========================================

SOLUTION 1: Clean and Rebuild (Recommended)
--------------------------------------------

Step 1: Close all apps
  - Close the OC人设盲盒 app if running
  - Close any Electron windows

Step 2: Run clean script
  Double-click: clean-build.cmd

Step 3: Rebuild
  npm run pack

========================================

SOLUTION 2: Manual Steps
-------------------------

Step 1: Close the app
  - Press Ctrl+Alt+Delete
  - Open Task Manager
  - Find "OC人设盲盒.exe" or "electron.exe"
  - End task

Step 2: Delete folders manually
  - Delete the "dist" folder
  - Delete the "dist-electron" folder

Step 3: Rebuild
  npm run pack

========================================

SOLUTION 3: Use PowerShell (If above fails)
--------------------------------------------

Open PowerShell as Administrator:

# Stop processes
Stop-Process -Name "OC人设盲盒" -Force -ErrorAction SilentlyContinue
Stop-Process -Name "electron" -Force -ErrorAction SilentlyContinue

# Wait a moment
Start-Sleep -Seconds 2

# Remove directories
Remove-Item -Path "dist" -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item -Path "dist-electron" -Recurse -Force -ErrorAction SilentlyContinue

# Rebuild
npm run pack

========================================

SOLUTION 4: Restart Computer
-----------------------------

If all else fails:
1. Restart your computer
2. Run: npm run pack

========================================

PREVENTION:
-----------

Always close the app before rebuilding:
1. Close all OC人设盲盒 windows
2. Wait 2-3 seconds
3. Then run build command

========================================

---------------

# Clean and rebuild (one command)
clean-build.cmd && npm run pack

clean-build.cmd
